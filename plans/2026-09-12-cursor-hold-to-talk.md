# Cursor Hold-to-Talk and ElevenLabs Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the cursor-native voice path use `Ctrl+Space` hold-to-talk, render the listening dots under the cursor, and connect the released recording to the server-owned ElevenLabs STT/TTS flow.

**Architecture:** Keep the desktop hotkey and microphone capture behind injectable adapters so the cursor overlay remains passive and testable. The service owns ElevenLabs credentials and performs batch Scribe v2 transcription followed by the grounded conversation controller and streamed Text-to-Speech; the renderer receives only state, transcript/reply data, and audio bytes. The existing typed control remains the fallback when microphone, hotkey, or provider access is unavailable.

**Tech Stack:** TypeScript, React, Vitest, React Testing Library, Fastify, browser `MediaRecorder`, ElevenLabs Speech-to-Text `scribe_v2`, ElevenLabs streamed Text-to-Speech, and the existing conversation/session contracts.

**Spec:** `specs/2026-09-12-cursor-financial-bodyguard-design.md`

## Global Constraints

- Hold-to-talk is `Control+Space`; key-down starts once, key-up submits, auto-repeat is ignored, and Escape/suspend/permission loss cancel the turn.
- Electron or the desktop host remains a background owner of the shortcut and overlay; no persistent chat window is introduced by this plan.
- ElevenLabs API keys, voice IDs, model IDs, and provider requests stay server-side; the renderer never receives or constructs provider credentials.
- Audio is memory-only, bounded by the existing 30-second/10 MB limits, and discarded after the turn or cancellation.
- Financial replies are generated by the existing grounded conversation controller; voice synthesis accepts only a session-owned `replyId`.
- Provider errors leave typed interaction available and expose a recoverable error state.
